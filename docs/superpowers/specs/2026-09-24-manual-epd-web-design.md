# 墨水屏本地网页手动上传设计

## 目标与验收边界

本阶段交付在 Microsoft Edge 中使用的本地网页。用户打开页面后自行点击“连接”选择墨水屏，选择本地图片、预览并可裁剪和调整抖动处理，最后自行点击“上传图片”。页面断线后保留当前图片与处理设置，用户可在同一页面点击“重连”重新建立连接，再自行决定是否上传。首次实体设备验收使用项目现有的 `epd_ble_test.png`，之后允许选择其他图片。

本阶段不实现一小时调度、自动蓝牙连接、断线自动重连、自动重试整张图片、自动构图、读取 GPT 或 Codex 额度、固件升级、硬件引脚配置、涂鸦及文字编辑。旧 Python/EXE 的 BLE 传输实现不进入运行链路。之前的桌面应用设计及本地网页定时发送计划均已被本设计取代，不能作为实施依据。

## 来源与技术基础

以用户已验证可手动连接和上传的 `https://epd-nrf5.lolicon.in/` 页面为传输基线。该站点当前公开交付的 HTML、CSS、五个 JavaScript 文件和图标可读取；实施时建立本地快照、记录来源与校验值，并再次核对许可信息和所取得文件的完整性。站点页面链接 `https://github.com/tsl0922/EPD-nRF5`，但当前尚不能断言该域名使用的文件与上游某次提交完全一致。仅复用必要的图片处理、Web Bluetooth 连接和图像传输逻辑，不重写 BLE 服务 UUID、命令编码、分包格式或刷新顺序。

本地页面使用固定的 `http://localhost:8765/` 来源，由只绑定 `127.0.0.1` 的轻量静态服务提供，并通过双击启动入口在 Edge 打开。启动入口只负责页面服务，不调用蓝牙 API；页面加载时不自动选择设备、连接或上传。服务需有明确的停止入口和端口占用提示，不得在端口被其他程序占用时悄悄换用另一来源。本阶段不制作 EXE。

## 连接、重连与发送行为

“连接”由用户点击后调用源站的设备选择流程；“重连”由用户点击后使用当前页面保存的 `BluetoothDevice` 对象重新建立 GATT 连接，不再次弹出设备选择器。页面尚未选过设备时“重连”不可用；页面刷新、关闭或浏览器未保留设备对象后，用户应重新点击“连接”。断线只更新状态并保留图片，不触发自动重连或自动发送。对于用户观察到的约五分钟断线现象，本设计不预设其原因或固定周期。

上传仅允许在图片已解码且设备已连接时由用户点击触发。上传期间禁止第二次上传以及相冲突的连接操作；图片处理仍沿用源站的画布、裁剪、抖动和协议路径。现有源码的 `write()` 可返回失败，但 `writeImage()` 与 `sendimg()` 没有完整传播该失败，实施时须在初始化、逐包写入和最终 `REFRESH` 之间建立明确的结果检查；任一阶段失败即停止本次传输，且不得在图片包失败后继续写入刷新命令。失败后不自动重发整张图，由用户确认设备与屏幕状态后自行决定下一步。

界面区分“未连接”“连接中”“已连接”“传输中”“写入失败”“传输命令已完成”等状态。最后一个状态只表示浏览器的 GATT 写入链路完成，不代表物理屏幕已完整刷新；实体画面仍由用户验收。日志保留时间、阶段和可理解的错误信息，避免将设备选择取消、连接失败、图片加载失败、分包写入失败混成同一条“失败”。

## 前端视觉与交互

视觉参考 `https://github.com/Noietch/EVA-CLIENT` 的公开页面与样式表，借鉴其暖灰画布、白色卡片、深色窄状态栏、克制的橙色主操作、细边框与轻阴影，但不复制多标签机器人控制台。配色以 `#F4F3F1` 画布、白色卡片、`#1F1E1C` 主文字与顶栏、`#E8590C` 主要操作为基准；连接、警告和失败各有文字说明，颜色仅作辅助。标题和操作文字优先中文，状态代码与数值可用等宽字体，字体使用本地系统回退以免页面依赖外部字体服务。

页面为单页双栏工作区。顶端状态栏显示应用名称、目标设备名称和连接状态；下方引导条提示当前操作。左侧操作卡片依次显示“连接”“重连”、图片选择、裁剪及抖动选项，右侧提供与墨水屏比例一致的较大画面预览；“上传图片”是唯一橙色主按钮。传输日志和高级传输参数分别收在可展开区域，不占据默认视图。高级区域保留源站上传所需的兼容参数及当前值，但不提供固件和硬件配置命令。窄窗口改为纵向排列，仍先显示状态与预览，再显示上传操作。

按钮启用状态必须与实际条件一致。“重连”只在同页已有设备对象且没有进行中的连接或传输时可点；“上传图片”只在连接有效、图片可用且没有进行中的传输时可点。断线后预览不清空，页面刷新后不伪装为仍已连接。错误提示在主界面可见，详细技术日志可展开查看；不使用仅靠颜色区分的状态标识。

## 后续扩展接口

后续的自动构图作为独立图片来源，产物仍进入同一预览与手动上传流程，不在当前页面放置尚未工作的入口，也不改变本阶段的手动连接原则。“GPT 额度”当前含义及可授权、稳定的数据来源均未核实，不能把未来自动读取写成已经具备的能力。后续阶段应先确定具体指标、授权方式和失败时的替代显示，再设计图片内容生成；本阶段不读取账户数据。

## 验证与交付判断

先用模拟 BLE 特征与固定测试图验证按钮状态、同页重连、页面刷新后的连接状态、图片处理、分包失败立即终止、刷新命令条件和重复点击保护，不需要真实蓝牙或等待一小时。然后在 Edge 中检查本地页面的连接按钮和设备选择器是否可用；实体设备测试由用户主动选择设备，先完成一次固定测试图上传并确认屏幕画面，再测试手动断线后的“重连”及另一张用户图片。任何自动测试均不能替代实体屏幕验收，且实体测试前应退出旧 EXE，避免两个程序同时占用蓝牙。

设计阶段不声称已经验证本地页面与当前实体设备的兼容性，也不声称查明了约五分钟断线的根因。交付时应说明源站快照与本地改动、启动和停止方式、图片操作流程、日志含义及已知限制。
