# 墨水屏本地图片上传

这是一个仅在本机运行的网页工具，供 Microsoft Edge 中手动连接墨水屏、预览图片并单次上传。当前版本没有定时任务、自动蓝牙连接、自动重连、自动重试、自动构图或 Codex 额度读取。界面借鉴 EVA-CLIENT 的色彩与信息层级，但图片编码和 Web Bluetooth 通信沿用源站逻辑；来源见 `SOURCE.md`。

## 启动与停止

需要 Windows、Microsoft Edge、Python 3（含标准库 `tkinter`），以及可供 Edge 使用的蓝牙适配器。在本目录双击 `launch.pyw`，脚本会把页面提供在 `http://localhost:8765/` 并打开 Edge，运行期间不显示控制台。若 `.pyw` 没有关联到 Python，可在 PowerShell 中运行 `pythonw web-epd\launch.pyw`；若 8765 端口已被占用，会弹出错误而不会占用别的服务。结束使用时双击 `stop.pyw`，它会先核实该端口确实是本工具才停止本地服务。仅关闭 Edge 标签页不会停止服务，但也不会在后台连接或上传图片。

## 手动操作

先退出此前的 BLE/EXE 测试程序，避免两个程序同时尝试使用设备。在 Edge 中打开本地页面后，点击“连接”，在 Edge 弹出的设备选择器中自行选择墨水屏；不要仅凭设备名称判断图片参数，连接后还应核对页面读到的驱动、画布尺寸和颜色模式。选择本地图片，检查右侧预览；若出现裁剪工具，先完成裁剪，再按需要调整抖动。确认预览及参数后，点击一次“上传图片”，等待状态文字；不要在未确认前重复发送。

首次验收可选用 `assets/epd_ble_test.png`，其 SHA-256 为 `F79E4BFAFA616C44F306BAA25476D3775775BE315886CFB0596B046C6500DF96`。只有你在实体屏幕上看到完整画面，才能认定这一轮成功；页面显示“传输命令已完成，请检查屏幕”只说明该轮浏览器写入与刷新命令完成，不保证电子纸已正确显像。

## 断线与故障

同一页面保留已选择的蓝牙设备对象，断线后可手动点击“重连”，无需再次打开设备选择器。刷新页面、关闭标签页或重新启动后，该对象不会保留，需要重新点击“连接”。页面不会在断线后自动重连，也不会自动重发图片；上传中断时会停止后续图片包和刷新命令，并显示失败信息。日志可在页面底部展开。

如果设备在 Edge 的选择器中不可见、连接失败、页面报错或屏幕显示不完整，先停止本轮尝试，记录页面状态和日志，再检查旧程序是否仍运行、设备电源与系统蓝牙状态。不要通过反复上传、修改固件、清屏或猜测驱动参数来排错。高级传输参数只供明确了解当前固件配置时核对；无效的 MTU 或确认间隔会被拒绝。

## 开发验证边界

自动测试可用 `python -m unittest discover -s web-epd/tests -p 'test_*.py' -v` 与 `node --test web-epd/tests/*.test.mjs` 运行，其中 Node.js 仅用于测试，不是运行网页的必要条件。测试使用假蓝牙对象，不会连接设备或写入电子纸。当前版本的实体显示结果、断线后重连效果及设备适配性需由使用者在 Edge 中手动验收；下一阶段的自定义构图将作为新的图片来源接入同一预览与手动上传流程。
